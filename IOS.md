# Radar — iOS (Capacitor) build guide

The native shell lives in `ios/` and is generated by Capacitor. It loads the
hosted web app (`server.url` in `capacitor.config.ts`), so a web deploy updates
the app content without a new App Store build.

## Requirements (cannot be done in this environment)

- A Mac with **Xcode 15+** and CocoaPods (`sudo gem install cocoapods`)
- An **Apple Developer Program** membership (99 USD / year) — required for
  signing, TestFlight and App Store submission
- The bundle id `app.lovable.radar` registered in App Store Connect (change it
  in `capacitor.config.ts` and `ios/App/App.xcodeproj` if you prefer another)

## Local build

```bash
npm install
npm run ios:sync
npx cap open ios        # opens Xcode
```

`npm run ios:sync` is mandatory before every archive. It both synchronizes the
native plugins and verifies that `CapacitorApp`, `CapacitorBrowser`, and the
`radar://` callback are present. Do not archive if this check fails.

For the Google sign-in fix, the successful output must include:

```text
Found 2 Capacitor plugins for ios:
@capacitor/app
@capacitor/browser
iOS Google sign-in check passed
```

In Xcode: select the `App` target → Signing & Capabilities → pick your team →
run on a device or simulator.

## TestFlight

1. Xcode → Product → Archive
2. Distribute App → App Store Connect → Upload
3. In App Store Connect, add testers under TestFlight

## Still needed before App Store submission

- Privacy policy URL (public page) — **required**
- Terms of use / EULA URL (required when the app sells subscriptions)
- App Privacy questionnaire (data collected: email, usage data)
- In-app purchase setup if subscriptions must be sold inside the app
  (Apple takes 15–30 % and blocks external payment links in most cases —
  Stripe web checkout can stay only if the app does not link to it)
- Screenshots: 6.7" iPhone (1290x2796) and 13" iPad if iPad is supported
- App name, subtitle, description, keywords, support URL, marketing URL
- Age rating, category (Finance or Productivity)
- Account deletion inside the app (Apple requirement for accounts)
- A demo account for App Review (email + password)
